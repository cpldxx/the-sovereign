Get started

  1. Install Docker

    Docker Desktop on Mac or Windows, Docker Engine on Linux.

  2. Run one command

    git clone https://github.com/cpldxx/the-sovereign.git
cd the-sovereign
./sovereign up

    Free, runs on Ollama. Needs about 24 GB of free memory.

  3. Give it a topic

    Open localhost:8000, create your account, and name a topic.
